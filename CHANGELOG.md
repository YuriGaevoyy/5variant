# Журнал изменений

## 1.0.0 (локальный кандидат, теги и релиз отложены до GitHub)

- шесть проектов .NET 10, решение `DeliveryService.slnx`, миграция InitialDelivery и демоданные;
- полный жизненный цикл отправления с серверными правилами и конечным статусом «Возврат»;
- три роли с объектным уровнем доступа курьера к списку, карточке, смене этапа и статистике;
- поиск, фильтры, импорт получателей из CSV с номерами ошибочных строк, экспорт в CSV/JSON/XML;
- собственный визуал WPF: тёмно-синяя навигация, светлая рабочая область, янтарный акцент «В пути»;
- 64 модульных и интеграционных теста, 8 UI-тестов, покрытие Core 94,8 %;
- 26/26 проверок живого HTTPS API на чистой SQLite; автономный ZIP Windows x64 проверен распаковкой и запуском.

## 0.9.0 (локальная контрольная версия)

- завершена интеграция Core, Data, Api и Desktop; вход всех ролей, базовые переходы и статистика;
- подготовлены диаграммы, спецификация API и файл запросов `requests.http`.

Примечание: теги `v0.9.0` и `v1.0.0`, удалённые ветки, Issues/Projects, PR и CI будут созданы только
после подтверждения целевого аккаунта и репозитория варианта 5.

## 0.9.0
