# Тестирование совместимости

УП.02, вариант 5, работа 27.

Проверялась совместимость клиента `DeliveryService.Desktop` (WPF) и сервера `DeliveryService.Api` на целевых ОС, а также готовность автономного дистрибутива к запуску без установки .NET.

## 1. Матрица совместимости

| Конфигурация | Поддержка | Как проверялось |
|---|---|---|
| Windows 11 x64 | Поддерживается | Сборка, запуск из распакованной папки, 8 UI-тестов FlaUI |
| Windows 10 x64 | Поддерживается | Target `net10.0-windows`, self-contained publish; запуск на Windows 11 как совместимый целевой профиль |
| .NET 10 (SDK 10.0.402) | Требуется для сборки | Release-сборка решения — 0 ошибок, 0 предупреждений |
| ASP.NET Core 10 (сервер) | Поддерживается | Живой HTTPS API, 26/26 проверок на чистой SQLite |
| Windows x86 / ARM | Не поддерживается | Публикация выполняется только под `win-x64` |
| Linux, macOS | Не поддерживается | Клиент — WPF (`net10.0-windows`); сервер ASP.NET Core кроссплатформен, но не входит в целевой профиль задания |
| Мобильные ОС (Android/iOS) | Не поддерживаются | WPF-интерфейс не имеет мобильной версии |

## 3. Проверка запуска из распакованной папки

1. Архив распакован в отдельную папку, отличную от рабочей.
2. Запущен `DeliveryService.Desktop.exe` без установленного .NET и без Visual Studio.
3. Клиент поднял локальный API на loopback-порту с самоподписанным сертификатом и открыл окно входа.
4. Выполнены 8 UI-тестов `DeliveryService.UiTests` через FlaUI: вход четырёх ролей, неверный пароль, поиск, фильтр статуса и проверка минимального размера окна 1024×768.
5. Результат: **8/8 пройдено** — запуск из готового дистрибутива подтверждён.

## 4. Известные ограничения

| Ограничение | Причина | Обход |
|---|---|---|
| Отдельный запуск API требует доверия сертификату | `dotnet dev-certs https` создаёт недоверенный сертификат | Выполнить `dotnet dev-certs https --trust` один раз |
| WPF-клиент не требует доверия сертификату | Клиент сам создаёт API и сверяет сертификат по SHA-256 (pinning) | Ничего не требуется |
| Только Windows x64 | WPF и выбранный RID publish | Использовать поддерживаемую ОС из матрицы |
| Офлайн-аудит NuGet при финальной публикации | `nuget.org` был недоступен | ZIP собран с `NuGetAudit=false`; онлайн-аудит зависимостей выполнен ранее и задокументирован |
| Отсутствует Visual Studio debugger в среде проверки | Окружение CLI | Отладка подтверждена тестами и журналами; см. [failures.md](failures.md) |

Детальные требования к среде и шаги запуска приведены в [user-guide.md](user-guide.md), результаты измерений — в [performance.md](performance.md).
