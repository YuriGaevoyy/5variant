# Обеспечение качества кода статическим анализом

УП.02, вариант 5, работа 25.

Качество проверяется без запуска программы: правила едины для всего решения и заданы файлами `.editorconfig` и `Directory.Build.props`. Проверка выполнялась на .NET 10.0.402; итоговая сборка решения `DeliveryService.slnx` из шести проектов в конфигурации Release — **0 ошибок, 0 предупреждений**.

## 1. Настройка статического анализа

| Файл | Параметр | Значение | Эффект |
|---|---|---|---|
| `.editorconfig` | `charset`, `end_of_line`, `insert_final_newline`, `trim_trailing_whitespace` | `utf-8`, `crlf`, `true`, `true` | Единое форматирование всех файлов |
| `.editorconfig` | `indent_style`, `indent_size` | `space`, 4 (2 для `csproj`, `props`, `xaml`, `xml`, `json`, `yml`) | Единые отступы |
| `.editorconfig` | `csharp_prefer_braces` | `warning` | Фигурные скобки обязательны |
| `.editorconfig` | `csharp_style_var_for_built_in_types` | `suggestion` | `var` для встроенных типов |
| `.editorconfig` | `CA1050`, `CA1305`, `CA1848` | `none` | Осознанно ослаблены: см. пояснение ниже |
| `Directory.Build.props` | `TargetFramework` | `net10.0` (`net10.0-windows` для Desktop и UiTests) | Одна целевая платформа на решение |
| `Directory.Build.props` | `Nullable`, `ImplicitUsings` | `enable` | Раннее выявление null-ошибок |
| `Directory.Build.props` | `EnableNETAnalyzers` | `true` | Встроенные анализаторы Roslyn (CA…/IDE…) |
| `Directory.Build.props` | `AnalysisLevel` | `latest` | Актуальный набор правил SDK 10.0.402 |
| `Directory.Build.props` | `TreatWarningsAsErrors` | `true` | Любое предупреждение, включая `NU1903`/`NU1904`, становится ошибкой сборки |
| `Directory.Build.props` | `NuGetAuditMode` | `all` | Аудит всех транзитивных зависимостей |
| `Directory.Build.props` | `NoWarn` | `NU1901;NU1902` | Подавлены только информационные уведомления по тестовым пакетам |

`NU1903` (уязвимость высокой важности) и `NU1904` (критическая) **не подавляются**: благодаря `TreatWarningsAsErrors=true` они останавливают сборку. Правила `CA1305` и `CA1848` отключены в `.editorconfig`, потому что форматирование чисел и дат задано явно через `CultureInfo.InvariantCulture` в `DeliveryService.Core/Exchange.cs`, а логирование низкочастотное; `CA1050` не применяется к служебным типам тестовых проектов.

## 2. Предупреждения до и после исправлений

| Предупреждение | Состояние до исправления | Действие | Итог |
|---|---|---|---|
| `NU1903` — уязвимый транзитивный пакет в цепочке.EntityFrameworkCore / JwtBearer | Обнаружен при аудите зависимостей | Обновление пакетов до **10.0.13** (`Microsoft.EntityFrameworkCore.Sqlite`, `Microsoft.AspNetCore.Authentication.JwtBearer`, `EntityFrameworkCore.Design`, `Mvc.Testing`, `Microsoft.Data.Sqlite`) | 0 |
| `NU1904` — критическая уязвимость | Не зафиксировано | Не подавляется; `*AsErrors` оставляет её ошибкой | 0 |
| `NU1901`, `NU1902` — информационные NOTICE по тестовым пакетам | Присутствуют в промежуточных restore | `NoWarn` только для этих кодов | 0 в сборке |
| `CA1707` — подчёркивания в именах методов тестов | Потенциально (правило провоцирует соглашение об именах xUnit) | Единый стиль имён в `DeliveryService.Tests` и `DeliveryService.UiTests` | 0 |
| `CA1305`, `CA1848`, `CA1050` — стиль, глобализация, логирование | Потенциально | `.editorconfig` + явный `InvariantCulture` в обмене данными | 0 |
| **Итог, Release, 6 проектов** | — | — | **0 ошибок, 0 предупреждений** |

Аудит NuGet включён (`NuGetAuditMode=all`); известные информационные предупреждения зафиксированы в [security.md](security.md). Ограничение среды: во время финальной публикации `nuget.org` был недоступен, поэтому ZIP собирался офлайн-восстановлением с `NuGetAudit=false` — это не отменяет результатов онлайн-аудита, но честно фиксируется как ограничение среды.

## 3. Связь с инспекцией

Чек-лист инспекции из Приложения В (имена и стиль, одна ответственность, дублирование и «магические числа», обработка исключений, освобождение ресурсов, `async/await` без `.Result`, секреты и личные данные, тесты на новую логику) применён локально; результаты — в [inspection.md](inspection.md). Значимая часть пунктов переложена на анализатор: `TreatWarningsAsErrors`, Roslyn CA/IDE-правила и аудит NuGet работают автоматически при каждой сборке. Парная инспекция с партнёром не выполнялась: репозиторий и партнёр не были предоставлены.
