# Руководство пользователя службы доставки

УП.02, вариант 5.

## Запуск

Приложение предназначено для Windows x64. Запустите `DeliveryService.Desktop.exe` из распакованной папки или откройте решение `DeliveryService.slnx` в Visual Studio и нажмите F5. Клиент самостоятельно поднимает локальный API и открывает окно входа. При отдельном запуске сервера он доступен по адресу `https://localhost:7130`; для доверия локальному сертификату выполните `dotnet dev-certs https --trust`.

При первом запуске применяются миграции и загружаются демоданные: не менее семи отправлений в разных статусах, два курьера и четыре учётные записи.

## Вход

Введите логин и пароль и нажмите «Войти».

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `Admin@2026!` | Администратор |
| `operator` | `Operator@2026!` | Оператор |
| `courier1` | `Courier1@2026!` | Курьер, назначения на часть отправлений |
| `courier2` | `Courier2@2026!` | Курьер, другие назначения |

При неверном пароле выводится сообщение. После пяти неудачных попыток за минуту вход блокируется на минуту.

## Рабочее окно

Слева расположена тёмно-синяя панель навигации с разделами «Отправления», «Получатели», «Статистика» и «Пользователи». Раздел «Пользователи» доступен только администратору; курьер видит только свои отправления. Вверху таблицы находятся строка поиска и фильтр по этапу, которые можно применять вместе.

В таблице показываются номер отправления, получатель, адрес, курьер и текущий этап. Этап подписан текстом: «Создано», «Принято на склад», «В пути», «Доставлено», «Возврат». Отправления «В пути» выделены янтарным цветом.

## Работа оператора

1. Откройте «Получатели» и выберите существующую запись или создайте новую: имя, телефон и адрес обязательны, электронная почта заполняется при наличии.
2. В разделе «Отправления» нажмите «Создать», укажите получателя, адрес, объявленную сумму и при необходимости описание. Отправление получит статус «Создано».
3. Откройте карточку и назначьте курьера из списка. Без назначения нельзя перевести отправление «В пути».
4. Переводите этапы кнопкой смены статуса в порядке: «Создано» → «Принято на склад» → «В пути» → «Доставлено». Для «Доставлено» заполните ФИО получателя в подтверждении и время доставки; сумма должна быть положительной.
5. Для возврата выберите «Возврат» и укажите причину не короче 5 символов. Возврат возможен с любого этапа, после него изменения закрыты.

Если кнопка перехода неактивна, наведите на неё указатель: подсказка объясняет, какое условие не выполнено.

## Работа курьера

Курьер видит только назначенные ему отправления в таблице, карточках, смене статуса и статистике. Запрос чужой карточки через интерфейс недоступен, а прямой запрос к API возвращает «отправление не найдено». Курьер переводит свои отправления в «Доставлено» и «Возврат» по тем же правилам, что и оператор. Разделы справочника, пользователей и экспорта скрыты.

## Работа администратора

Администратор видит все отправления и получателей, может создавать и редактировать записи, назначать курьеров, менять статусы, пользоваться импортом, экспортом и статистикой. В разделе «Пользователи» отображаются логины, имена и роли всех учётных записей.

## Импорт получателей

1. Подготовьте файл UTF-8 с заголовком `Name,Phone,Address,Email`. Обязательны имя, телефон и адрес; электронная почта может быть пустой.
2. В разделе «Получатели» нажмите «Импорт» и выберите файл.
3. При успехе приложение сообщит число добавленных записей. При ошибке будут показаны номера строк; в этом случае не сохраняется ни одна запись файла — исправьте файл и повторите.

Ограничение файла — 1 МиБ и 5 000 записей.

## Экспорт отправлений

В разделе «Отправления» нажмите «Экспорт» и выберите формат CSV, JSON или XML. Выгружается текущая выборка с учётом поиска и фильтра статуса. Файл сохраняется с понятным именем; время в выгрузке указано в UTC. Экспорт доступен администратору и оператору.

## Статистика

Раздел «Статистика» показывает количество отправлений по каждому этапу, общую и среднюю объявленную сумму, средний срок выполнения, число доставленных, возвращённых и находящихся «В пути» отправлений. У курьера показатели рассчитываются только по его отправлениям. Если доставленных отправлений нет, средний срок не отображается.

## Выход

Нажмите «Выйти» в правом верхнем углу. Сеанс завершается на сервере, и приложение возвращается к окну входа. Повторное использование прежнего токена невозможно.
