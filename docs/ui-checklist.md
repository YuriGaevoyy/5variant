# Чек-лист интерфейса WPF

УП.02, вариант 5, работа 4.

Проверки выполняются на собранном `DeliveryService.Desktop.exe` при минимальном размере окна 1024×768 и при максимизированном окне. Интерактивные элементы должны определяться в дереве автоматизации по `AutomationId`. Результат «Пройдено» означает визуальную и автоматизированную проверку через FlaUI.

## Основной чек-лист

| № | Элемент или сценарий | Что проверяется | Результат |
|---:|---|---|---|
| 1 | Окно входа | При запуске открывается форма входа, поля «Логин» и «Пароль», кнопка «Войти» доступны | Пройдено |
| 2 | Окно входа | Пароль маскируется, сообщение об ошибке отображается на русском | Пройдено |
| 3 | Вход всех ролей | `admin`, `operator`, `courier1`, `courier2` открывают рабочее окно | Пройдено |
| 4 | Левая навигация | Тёмно-синяя панель слева, пункты «Отправления», «Получатели», «Статистика», «Пользователи» | Пройдено |
| 5 | Таблица отправлений | Колонки «№/отправление», «Получатель», «Адрес», «Курьер», «Этап» заполнены | Пройдено |
| 6 | Цвета статусов | «В пути» выделен янтарным акцентом, остальные статусы — спокойными цветами | Пройдено |
| 7 | Текстовые подписи | Статусы показываются словами: «Создано», «Принято на склад», «В пути», «Доставлено», «Возврат» | Пройдено |
| 8 | Поиск | Строка поиска находит по номеру, получателю, телефону, адресу и курьеру | Пройдено |
| 9 | Фильтр статуса | Выбор статуса сужает таблицу, пункт «Все статусы» возвращает полный список | Пройдено |
| 10 | Сочетание фильтров | Поиск и фильтр применяются одновременно | Пройдено |
| 11 | Карточка отправления | Поля получателя, адреса, суммы, курьера, этапа и версии читаемы без прокрутки | Пройдено |
| 12 | Смена статуса | Кнопка перехода доступна только для допустимого следующего этапа | Пройдено |
| 13 | Возврат | Поле причины появляется при выборе «Возврат» и требует не менее 5 символов | Пройдено |
| 14 | Доставлено | Поля подтверждения получения (ФИО) и времени доставки обязательны | Пройдено |
| 15 | Справочник получателей | Таблица и формы создания и редактирования доступны администратору и оператору | Пройдено |
| 16 | Импорт | Выбор CSV и вывод номеров ошибочных строк в понятном виде | Пройдено |
| 17 | Экспорт | Доступны CSV, JSON и XML; файл скачивается с корректным именем | Пройдено |
| 18 | Статистика | Показатели по статусам, суммы и средний срок отображаются в виде карточек | Пройдено |
| 19 | Пользователи | Раздел виден только администратору | Пройдено |
| 20 | Права курьера | Курьер видит только свои отправления и не видит «Пользователей» и «Получателей» | Пройдено |
| 21 | Выход | Кнопка «Выйти» доступна всем ролям и возвращает к окну входа | Пройдено |
| 22 | Минимальный размер | При 1024×768 элементы не перекрываются, подписи не обрезаются | Пройдено |
| 23 | AutomationId | Ключевые поля, кнопки и таблицы обнаруживаются в дереве автоматизации | Пройдено |

## Дополнительные пункты

| № | Дополнительный пункт | Проверка | Результат |
|---:|---|---|---|
| Д1 | Состояние пустой выборки | При отсутствии результатов таблица показывает пояснение, а не пустой кадр | Пройдено |
| Д2 | Отключённые действия | Недопустимые переходы и кнопки неактивны и имеют подсказку с причиной | Пройдено |
| Д3 | Длинные значения | Длинные ФИО и адреса переносятся или сокращаются с подсказкой без разрушения вёрстки | Пройдено |
| Д4 | Формат суммы | Денежное поле показывает два знака после запятой и не принимает отрицательное значение | Пройдено |
| Д5 | Время доставки | Время показывается в локальном виде, а в API передаётся в UTC | Пройдено |

Итог: интерфейс соответствует требованиям NFR-05 и пригоден для автоматизированных сценариев проекта `DeliveryService.UiTests`.
